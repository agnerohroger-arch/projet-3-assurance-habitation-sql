# Projet 3 — Analyse d'une base de données d'assurance habitation avec SQL

## Contexte
Projet réalisé dans le cadre de ma formation Data Analyst chez OpenClassrooms.

L'objectif est d'exploiter une base de données d'assurance habitation pour analyser les contrats, les clients et leur répartition géographique.

## Problématique métier
Comment interroger et analyser une base de données d'assurance habitation afin de produire des informations utiles à la prise de décision ?

## Méthodologie
1. Étude de la structure des données et des besoins métier.
2. Préparation et exploitation de la base de données relationnelle.
3. Rédaction de requêtes SQL pour extraire et agréger les informations.
4. Analyse des contrats, des clients et de leur répartition géographique.
5. Documentation de la démarche et des résultats.

## Compétences mobilisées
- SQL
- Bases de données relationnelles
- Jointures et agrégations
- Analyse de données
- Documentation technique
